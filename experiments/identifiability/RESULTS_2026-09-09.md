# Results: 2026-09-09

## Claim status

The synthetic symmetry/commutator design is computationally promising relative to its declared nuisance family. The synthetic boundary-differential design is rejected as robustly identifiable after adversarial nuisance expansion.

## Interpretation

A large raw response is not sufficient. The relevant quantity is the whitened component of the target signature outside the calibrated nuisance tangent space. The boundary experiment illustrates the failure mode: a target can be detectable under a narrow model and nearly degenerate after plausible conventional modes are admitted.

## Falsification result

Adding an exact target-shaped nuisance to the commutator family collapses identifiability to numerical zero. This is a required sanity check: observationally equivalent mechanisms cannot be distinguished by post-processing.

## Derived repository-level insight

The repository's existing claim/falsification architecture and its physics forward models are complementary but currently separated conceptually. The identifiability layer supplies a quantitative bridge: a claim can carry a target signature, nuisance family, covariance model, and promotion metric in addition to a prose falsifier. This does not replace the canonical registry; it makes a subset of falsifiers executable.

For a target derivative `t` and nuisance Jacobian `N`, the promotion statistic is based on `r = (I - P_N)t`. A claim whose `r` collapses under justified nuisance expansion remains model-degenerate even if its raw signal-to-noise ratio is high.

## New cross-domain deductions

1. The existing optical database plus Lifshitz kernel can generate physical target derivatives instead of hand-authored response curves.
2. The registry can store the nuisance family and covariance provenance alongside each experiment, making claim promotion reproducible.
3. Symmetry reversal is a computational resource: target and nuisance terms with different parity can be separated before fitting.
4. Multi-observable closure is stronger than single-curve agreement because one parameter set must predict several independent observables.
5. Identifiability should converge under numerical refinement: a forward model is not inference-ready merely because its mean observable converges if its parameter-sensitivity/Fisher geometry does not.
6. The same projection/Schur-complement kernel can score any differentiable forward model in the workspace, creating a common falsification API without asserting a common physical mechanism.
7. A claim registry can distinguish `detectable` from `identifiable`: high signal-to-noise is insufficient when the target lies inside the conventional nuisance span.
8. The repository's existing falsification culture can be strengthened by recording the strongest nuisance family survived by each claim, creating a monotone adversarial-evidence ladder rather than a binary pass/fail label.
9. The boundary prototype's standardized nuisance condition number (~8.6e4) reveals a second failure mode beyond physical degeneracy: nuisance coordinates themselves can be numerically ill-conditioned. Production inference therefore needs rank-revealing QR/SVD and explicit effective-rank reporting.
10. Local orthogonality is necessary but not sufficient for nonlinear nuisance models: curvature of the nuisance manifold can imitate the target away from the expansion point. Production L3/L4 tests must therefore include profile/manifold searches, not only Jacobian projection.
11. A model can converge numerically while its inference geometry does not. Therefore convergence testing should include principal angles and Fisher eigenvalues across refinement levels.
12. Claim provenance can become executable: a content-addressed bundle of model commit, data hashes, nuisance definitions, covariance, schedule, and verdict is sufficient to reproduce an evidential-level calculation.
13. The best first physical integration is Casimir-Lifshitz, not because the other domains are less interesting, but because the repository already has the forward kernel, geometry abstractions, optical database, and falsification infrastructure needed to replace the synthetic target with a traceable prediction.
