# Negative Dimension Clarifications

This note defines the allowed meaning of "negative dimension" in the
open_gororoba claim registry. The phrase is a toy-model shorthand for an
analytically continued dimension-like parameter in spectral and diffusion
operators. It is not a claim that physical spacetime has a negative topological
dimension.

The registry uses this boundary for C-008, C-011, and C-012. C-008 is a closed
toy result about the mapping from an operator parameter to a spectrum. C-011 is
a closed obstruction result for the sedenion-gravastar analogy. C-012 refutes
the literal physical interpretation of "dark energy as negative dimension
diffusion."

## Mechanism Boundary

The admissible mechanism is an operator family whose parameter is allowed to
take analytically continued values. In that setting, symbols such as `D_eff =
-1.5` name a fitting or indexing parameter, not a measured spacetime dimension.

Physical claims require an independent dynamical model, observables, and
calibration surfaces. A numerical match obtained by tuning `D_eff` is evidence
for a toy correspondence only. It does not verify a cosmological mechanism.

## Falsifier

The toy interpretation would become a physical claim only if a concrete
Lagrangian, stress-energy tensor, or observational pipeline produced the same
parameter without post-hoc tuning and survived the registered multiprobe gates.
Absent that mechanism, the correct status is toy, obstructed, or refuted as
recorded in the claims registry.
