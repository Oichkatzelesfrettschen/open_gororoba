Post-1997 Cayley-Dickson Formalization Sources
==============================================

WHY
---
The Brown and Moreno proof stack is now strong enough to support modern
post-1997 Cayley-Dickson papers, but the repo needs a clean routing map before
new theorem lanes are added.

WHAT
----
This file records the immediate source-to-formalization plan for modern CD
papers while the larger Jacobson and Freudenthal physical-source intake is
handled separately.

HOW
---
Route each paper as one of:

- Rocq-first: compact finite theorem, algebraic identity, or proof interface.
- Rust-first: large enumeration, table extraction, graph census, or numeric
  certificate generator.
- Paired: Rust produces finite witnesses or tables; Rocq certifies the
  theorem-facing invariant.

Routing order
-------------

1. Baez/Elduque normalization: define shared vocabulary and interfaces only.
2. Bales/Flaut sign normalization: align twisted products with repo XOR signs.
3. Bremner-Hentzel identities: land small reusable CD-process identity surfaces.
4. Moreno 2005 zero-divisor spectrum: extend the Moreno 1997 theorem stack.
5. Biss-Dugger-Isaksen annihilators: add annihilator interfaces and bounds.
6. de Marrais/Cawagas: certify finite sail-loop and automorpheme structures.
7. Chan-Dokovic: certify representative sedenion subalgebra classes.
8. Reggiani: split standard-ZD and partner-graph logic into a paper lane.
9. Wilmot: cross-link counts, retraction theorems, and Reggiani/de Marrais data.
10. Only after these lanes are stable, revisit full differential-geometry claims.

Gate expectations
-----------------

- Run `make -C proofs rocq-makefile-check` before compiling new .v
  files (the rocq-makefile-check target lives in `proofs/Makefile`;
  invoking `make rocq-makefile-check` from the repo root has no rule
  by design, since the root Makefile is workspace-wide).
- Run make -C proofs vos after adding a proof file to _RocqProject.
- Run the smallest target .vo build before wider make -C proofs check.
- Run Rust paired tests with cargo clippy --workspace -- -D warnings before
  marking a paper lane as verified.
- If registry rows change, mutate the SQLite canonical control plane first and
  regenerate compatibility exports atomically.
