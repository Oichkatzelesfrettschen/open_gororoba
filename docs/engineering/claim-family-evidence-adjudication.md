The independent Ward oracle shares the physics tensors and quadrature with the
producer. Its independence covers contraction order, lower-point assembly and
intercept arithmetic; the oracle does not independently derive the integrand.
Likewise, a finite-grid topology admission establishes sampled gaps and link
conditioning, rather than a global band-isolation proof.

Canonical writes use `gororoba-db claim correct-content`, `claim set-evidence`
and typed `claim transition` specifications. Content correction checks the expected
statement and locator atomically and retains both complete prestate values. A
stale prestate or failed audit insertion aborts the correction transaction.
Experiment registrations bind the actual replay producer instead of reusing an
unrelated historical experiment ID.

The execution-planning verifier admits integration tests by
`cargo-test:<package>:<target>` after checking the Cargo manifest and source path.
External tools use versioned identities declared in
`plans/external-execution-targets.toml`; the declaration binds a hashed identity
receipt and its source receipt. Registration verifies retained evidence and leaves
runtime availability and scientific reproduction as separate predicates.

Replays use the commands and input/source hashes recorded in each evidence receipt.
The geometric protocol seals its source files and Cargo.lock; formatting or changing
those files requires a separately declared replay amendment. Export canonical views
with `provenance export-control-plane`, then run `make registry-integrity` and the
repository validation chain. Publication requires the SQLite delta, generated views,
contracts and retained evidence in the same reviewed change.
