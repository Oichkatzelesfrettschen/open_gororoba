% Title: Composable SIMD/GPU Optimization for Non-Associative
%        Hypercomplex Algebra: Cache-Geometry-Determined Performance
%        Across Four Microarchitectures

Non-associative hypercomplex multiplication in the Cayley--Dickson tower
requires four recursive $O(D \log D)$ calls per associator evaluation,
making dimensions beyond 64 impractical without cache-aware optimization.
We present a composable six-layer stack in Rust achieving up to
2{,}508\,kvec/s at 32D (Apple~M1) and characterize a sharp
\emph{L1d-determined performance cliff}: throughput drops $70\times$ at
128D on 32\,KB L1d (Zen3) but only $3\times$ on 256\,KB L1d
(Cobalt~100), because the recursive workspace ($6D$ floats per level)
overflows the smaller cache.  Measured across four microarchitectures
(AMD Zen3 96\,MB 3D V-Cache, Intel Xeon 32\,MB L3, ARM Cobalt~100
256\,KB L1d, Apple~M1 unified memory), the optimal embedding dimension
$D_\mathrm{opt} \approx L_{1d} / (6 \cdot \mathsf{sizeof}(f32))$
is set by cache geometry, not algebra.  Our layers---SIMD three-tier
dispatch, zero-allocation workspace, SoA cache layout, Cariow
$O(N^{1.58})$ multiply, adaptive norm-proxy sampling, and
hardware-accelerated kernels---compose to enable a 48-million-record
heliospheric atlas at 32D that was previously infeasible on consumer
hardware.  A GPU path extends to six precision levels (FP64--INT4)
via 23 CUDA kernels.
