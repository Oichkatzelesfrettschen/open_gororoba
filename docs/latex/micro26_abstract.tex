% Title: Composable SIMD/GPU Optimization for Non-Associative
%        Hypercomplex Algebra: 289x Speedup via Six Independent Layers

Six independently-designed optimization layers for Cayley--Dickson
non-associative algebra compose multiplicatively, achieving 289$\times$
end-to-end speedup on a 6-core Zen4 consumer CPU.  The target
primitive---the CD associator, a trilinear form requiring four recursive
$O(D \log D)$ multiplications at dimension~$D$---becomes impractical
beyond 16D without such composition.  Our layers: SIMD three-tier
dispatch (3--4$\times$), zero-allocation workspace overlap
(1.5$\times$), structure-of-arrays cache layout (2.8$\times$), Cariow
$O(N^{1.58})$ fast multiply (2--3$\times$), adaptive norm-proxy sampling
(10$\times$), and hardware-accelerated distance kernels
(259$\times$).  Each layer is independently benchmarkable.  The
resulting throughput (1{,}155\,kvec/s at 64D) enables a
48-million-record heliospheric atlas at 32D embedding spanning five
orders of magnitude across 0.32--167\,AU---a workload previously
infeasible on consumer hardware.  A GPU path extends to six precision
levels (FP64--INT4) via 23 CUDA kernels.
